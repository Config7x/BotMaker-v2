# BotMaker v2: بسته آزمایشی VPS

این نسخه برای **تست شخصی مالک روی VPS مجزا** است، نه میزبانی عمومی سورس کاربران. نصب واقعی روی VPS هنوز از این محیط تأیید نشده است. ۹۷ تست محلی گذشتند، اما Telegram، Docker و HTTPS در تست‌ها شبیه‌سازی شدند.

## پیش‌نیاز

- Ubuntu VPS با Node.js **20.x** و npm؛ برای سورس سفارشی Docker daemon هم لازم است. به خاطر دسترسی Docker به میزبان، فقط روی VPS آزمایشی اختصاصی اجرا کنید، نه سرور حاوی داده مهم.
- دامنه‌ای با DNS متصل به VPS و گواهی HTTPS معتبر. در reverse proxy مسیرهای `/webhook/*` را بدون تغییر به `127.0.0.1:3000` برسانید. پورت 3000 را عمومی باز نکنید؛ 443 باید از اینترنت قابل دسترس باشد.
- شناسه عددی حساب تلگرام مالک و یک **ربات کنترل جدید** ساخته‌شده در BotFather. از توکن @pos7xaibot یا هر ربات فعال دیگر استفاده نکنید، چون Telegram برای هر ربات فقط یک webhook فعال دارد و سرویس قبلی قطع می‌شود.

## نصب و تست اولیه

دو مسیر پیکربندی وجود دارد:

• روش ساده (پیشنهادی برای VPS): با اسکریپت idempotent که سرویس systemd هم نصب می‌کند و `.env` را به‌صورت تعاملی می‌سازد:

```bash
git clone https://github.com/Config7x/BotMaker-v2.git
cd BotMaker-v2
sudo bash install.sh
```

• روش دستی/آزمایشی محلی: پیکربندی `config.json` می‌سازد (بدون systemd):

```bash
bash setup.sh
```

اسکریپت فقط پیکربندی محلی، نصب وابستگی و تست را انجام می‌دهد. Node.js، Docker یا reverse proxy را روی سرور تغییر نمی‌دهد. توکن را در چت یا لاگ عمومی نفرستید. `config.json` شامل توکن و کلید رمزنگاری است: آن را منتشر نکنید، مجوز آن باید 600 باشد و هنگام بروزرسانی حذفش نکنید. فایل‌های `data/` را هم حفظ کنید.

نمونه تنظیم Caddy (در صورت نصب و مالکیت دامنه):

```caddyfile
bots.example.com {
    reverse_proxy 127.0.0.1:3000
}
```

بعد از فعال‌شدن HTTPS، در ترمینال پروژه اجرا کنید:

```bash
npm start
```

برای آزمایش HTTP روی همان VPS: `curl http://127.0.0.1:3000/health`. سپس در گفتگوی خصوصی ربات کنترل `/start`، `/create_bot`، انتخاب قالب، و توکن **ربات تست جدید** را بفرستید. تا زمانی که `ADMIN_ONLY` را عمداً تغییر نداده‌اید، فقط مالک می‌تواند از ربات کنترل استفاده کند. ۱۱ قالب درون‌پروسه (shop، uploader، post_composer، channel_manager، quiz، downloader، multi_downloader، music_downloader، music_bot، universal_poster، video_downloader) به‌علاوه ۲ قالب کانتینری فقط-Pro/VIP (#۱۰ فروشگاه VPN و #۱۱ اسکرپر کانفیگ) که هر نمونه در کانتینر Docker اختصاصی با gVisor اجرا می‌شود. جزئیات کامل در `README.md`.

## سورس سفارشی (فقط آزمایش مالک)

**احتیاط:** اجرای کد اختصاصی با Docker bridge برای دسترسی به Telegram و نصب وابستگی‌ها به شبکه دسترسی دارد. Docker به‌تنهایی جداسازی امنیتی قوی برای کاربران ناشناس عمومی نیست. Docker/کاربر عضو گروه docker دسترسی قدرتمندی به میزبان دارد. سورس اشخاص ناشناس را نپذیرید. روی VPS اختصاصی و موقت تست کنید.

برای شروع آزمایش سورس، بعد از `docker info` در ترمینال آزمایشی اجرا کنید:

```bash
LAB_MODE=true TEST_LAB_MODE=true REVIEWED=true LAB_ALLOW_NETWORK=true npm start
```

در ربات کنترل خصوصی `/source` را بفرستید؛ یک ZIP حداکثر ۱۰ مگابایت با `manifest.json` در ریشه آپلود کنید. مثال:

```json
{"runtime":"node20","start":"node index.js"}
```

یا `{"runtime":"python3.11","start":"python main.py"}`. فایل باید با متغیر محیطی `TELEGRAM_TOKEN` کار کند و خودش polling انجام دهد. سورس Node با `npm install --ignore-scripts --omit=dev` و Python با `pip install -r requirements.txt` **فقط در کانتینر** وابستگی‌ها را نصب می‌کند. پس از گزارش و ثبت توکن ربات اختصاصی، `/source_run src_ID` را بفرستید. این دستور webhook قبلی **همان ربات اختصاصی** را حذف می‌کند تا polling کار کند. برای گزارش `/source_logs src_ID`، برای توقف `/source_stop src_ID` و برای وضعیت `/source_status src_ID`.

اگر سورس ناسازگار بود، `/source_rewrite src_ID` را بفرستید. تنها پس از تأیید جداگانه `/source_rewrite_confirm src_ID`، فایل‌های متنی برای سرویس AI خارجی ارسال می‌شوند. باید `AI_API_KEY` معتبر را فقط به عنوان متغیر محیطی روی VPS تعریف کنید. حذف خودکار الگوهای رایج رمزها تضمین عدم افشای تمام اسرار نیست: قبل از تأیید، اسرار را از سورس بردارید. خروجی AI پیشنهادی است و بدون بررسی انسانی صحت یا امنیت آن تضمین نمی‌شود. تنها پس از بررسی، `/source_use_candidate src_ID` را اجرا کنید.

## عیب‌یابی و محدودیت‌ها

`npm test` را روی همان VPS اجرا کنید. اگر در اجرای واقعی خطایی دیدید، **متن خطا پس از حذف توکن، دامنه خصوصی و کلیدها** را ارسال کنید. این نسخه سیستم نصب سرویس پس‌زمینه، محافظت پیشرفته شبکه برای کانتینرها، میزبانی عمومی سورس‌های ناشناس، یا اثبات عملکرد همه قابلیت‌ها روی VPS ندارد. Node.js نباید پشت پروکسی با قابلیت نمایش مسیرها/توکن‌ها لاگ عمومی منتشر کند.
